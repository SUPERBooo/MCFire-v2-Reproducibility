# MCFire Reproducibility Code

This archive contains the release-metadata verification/correction utility (`repair_release_metadata.py`) and the statistical, ablation benchmark, trajectory extraction, and figure generation scripts (`tasks123_statistics.py`, `tasks45_benchmarks.py`, `restore_recorded_cv_2023.py`, `task6_extract_trajectories.py`, `plot_figure5.py`, `validate_and_export_evidence.py`, `build_report.py`), together with the recorded Python dependency list (`requirements.txt`). It excludes raw satellite imagery, full tensor archives, credentials, caches, and backup copies.

The scripts are designed to run against the frozen annual release packages (`MCFire_Dataset_v2_2021_RELEASE` through `MCFire_Dataset_v2_2025_RELEASE` and `MCFire_Dataset_v2.1_2022_TERRAIN_AUXILIARY`).
